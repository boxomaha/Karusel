# Шевроны — калькулятор себестоимости

Веб-калькулятор себестоимости шевронов по данным книги `ШЕВРОНЫ.xlsx`. Площади: 50, 100, 300, 600 см².

## Открыть
https://boxomaha.github.io/Karusel/

## Как работает вход
- Первой показывается форма логина и пароля.
- `calculator.html` и `calculator.js` загружаются браузером **только после** успешной проверки.
- Пароль в открытом виде в файлах не хранится: используется локальная проверка PBKDF2-SHA256.
- После перезагрузки страницы требуется повторная авторизация.

**Ограничение безопасности:** это *клиентская* проверка, а не настоящая серверная авторизация. GitHub Pages — публичный статический хостинг. Файлы `calculator.js`, `calculator.html` и история GitHub общедоступны, даже если интерфейс закрыт формой входа. Нельзя считать данные защищёнными от целенаправленного доступа. Для конфиденциальных данных нужен хостинг с серверной авторизацией и закрытым хранением данных.

## Публикация
Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`.

Сайт статический: серверной базы данных и совместного редактирования нет.
