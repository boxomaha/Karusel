# Шевроны — чат по себестоимости

**Сайт:** https://boxomaha.github.io/Karusel/

Главный интерфейс — чат на русском языке вместо ручных полей ввода. После авторизации задайте вопрос, например:

- «Посчитай 150 шевронов площадью 47 см²» (категория 50 см²).
- «А на 200 штук?».
- «Сравни 47 и 51 см² при тираже 200 шт» (категории 50 и 100 см²).
- «Почему себестоимость снижается при увеличении тиража?».
- «Какой тираж нужен для 50 рублей за штуку при площади 47 см²?».
- «Сколько получится шевронов 50 см² из 2 погонных метров?».

**Любая фактическая площадь от более 0 до 600 см²:** округление всегда **вверх** до 50, 100, 300 или 600 см². Примеры: **47 → 50**, **51 → 100**, **301 → 600**, **601 → расчёт запрещён**. Математика выполняется строго по локальной расчётной модели в `calculator.js`; значения не выдумываются ИИ. Чат хранит контекст по площади и тиражу на протяжении открытой страницы.

## Состояние ИИ

**По умолчанию** работает *локальный разбор команд* с ограниченным набором русских фраз. Это **не полноценная языковая модель**, несмотря на разговорный интерфейс. При подключении отдельного серверного API в `index.html` включается распознавание произвольных запросов настоящей ИИ-моделью.

Серверный обработчик с проверкой пароля и защитой API-ключа находится в [worker/](worker/README.md). Его необходимо опубликовать в Cloudflare Workers и самостоятельно предоставить секреты провайдера ИИ. Без сервера ключ ИИ размещать на GitHub Pages нельзя.

## Авторизация

Первой страницей показывается форма входа. До успешной проверки браузер **не запрашивает** `calculator.html`, `calculator.js`, `chat-engine.js` и `chat-ui.js`. Пароль не хранится в исходном коде в открытом виде: используется локальная PBKDF2-SHA256 проверка.

**Ограничение безопасности:** это проверка интерфейса, не защита файлов. GitHub Pages и публичная история GitHub доступны посторонним без авторизации. Технически подготовленный человек может прочесть исходные параметры расчёта. Для действительно конфиденциальных данных нужны серверное хранение и настоящая серверная авторизация. Доступ к ИИ API отдельно контролируется Worker.

## Файлы

- `index.html` — экран входа, оформление чата, последовательная загрузка модулей.
- `calculator.html` — интерфейс чата.
- `calculator.js` — проверенная расчётная модель.
- `chat-engine.js` — разбор локальных фраз, контекст, объяснения и сравнения.
- `chat-ui.js` — сообщения и карточки результатов.
- `worker/worker.js` — опциональный защищённый API настоящего ИИ.
