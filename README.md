# Шевроны — калькулятор себестоимости

Веб-калькулятор на основе исходной книги `ШЕВРОНЫ.xlsx` с четырьмя площадями: 50, 100, 300 и 600 см².

## Использование

Откройте `index.html` в браузере либо опубликуйте сайт через GitHub Pages: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`.

Таблицы для тиражей 10–300 шт. строятся из параметров исходной книги с помощью формул в `data.js`; доступен расчёт произвольного тиража, выбор площади, подсветка строк и печать в PDF. Сайт статический и не передаёт данные на сторонний сервер.
