# Алгоритм калькулятора шевронов

Источник: исходная таблица `ШЕВРОНЫ.xlsx` с четырьмя листами `50см2`, `100см2`, `300см2`, `600см2`. Реализация находится в `/calculator.js`, разбор текста и диалог — в `/chat-engine.js`, опциональное распознавание через языковую модель — в `/worker/worker.js`.

## 1. Округление фактической площади (правило от 29.10.2026)

Пользователь указывает **фактическую площадь** (любое положительное число в квадратных сантиметрах). Расчётная площадь — **наименьшая из 50, 100, 300, 600 см², не меньшая фактической**:

| Введённая площадь | Расчётная категория |
|---|---|
| 0 < S ≤ 50 | 50 см² |
| 50 < S ≤ 100 | 100 см² |
| 100 < S ≤ 300 | 300 см² |
| 300 < S ≤ 600 | 600 см² |
| S > 600 | отказ в расчёте |
| S ≤ 0 или нечисловая | ошибка ввода |

Значения **47 → 50**, **50 → 50**, **51 → 100**, **100 → 100**, **101 → 300**, **300 → 300**, **301 → 600**, **600 → 600**, **601 → отказ**.

Для дробных площадей правило такое же: например, `50,01 → 100`; не округлять площадь до целого перед применением категорий.

При отказе **не рассчитывать суммы**, не выбирать «последнюю категорию» автоматически и не подменять фактическую площадь. Показать понятное сообщение об ограничении.

## 2. Себестоимость

Пусть `T` — расчётная категория, `N` — тираж, `p=DATA[T]`, где:
- `B` — шевронов в заготовке;
- `C` — заготовок с погонного метра;
- `D` — стоимость погонного метра;
- `G`, `H` — начальная стоимость вышивки на заказ и переменная стоимость на заготовку;
- `J`, `K` — начальная стоимость лазера на заказ и переменная стоимость на заготовку.

Формулы:

```text
Материал_шт = D / (C * B)
Вышивка_шт = G / N + H / B
Лазер_шт   = J / N + K / B

Себестоимость_шт = Материал_шт + Вышивка_шт + Лазер_шт
Себестоимость_заказа = N * Себестоимость_шт

Постоянная_часть_заказа = G + J
Переменная_часть_шт = D/(C*B) + (H+K)/B
Себестоимость_шт = Постоянная_часть_заказа/N + Переменная_часть_шт
```

Допустимый тираж: целое число от **1 до 1 000 000 штук**. Отображение денег — 2 знака после запятой; внутри расчётов округления нет.

**Важно:** смена фактической площади внутри одной категории не меняет себестоимость. Например, 31 и 47 см² при равном тираже используют одинаковую категорию 50 см².

## 3. Обработка пользовательских фраз

1. Из текста извлечь **фактические** площади (включая дробные), не преобразуя их на этапе распознавания. Например, `47 см²` остаётся 47.
2. Извлечь тираж, намерение (расчёт, объяснение, сравнение, подбор тиража, материал на погонный метр).
3. Дополнить отсутствующие параметры из предыдущего контекста разговора, если это корректное уточнение.
4. **Проверить** площадь через `tierFor(S)`, включая недопустимые значения, ещё до расчётов и отображения итогов.
5. Применять все финансовые формулы исключительно к значению `DATA[tierFor(S)]`.
6. Отобразить **и введённую**, и расчётную площадь: `47 см² → расчёт по 50 см²`.
7. Для сравнения площадей округлять каждую **независимо**. Если обе попадают в одну категорию, себестоимость одинаковая при равном тираже.
8. Если внешний ИИ подключён, он **только извлекает параметры** и не считает суммы. Проверка категорий и финансовые расчёты всё равно на стороне программы.

## 4. Защита данных и версия

Исходные ставки и формулы сейчас присутствуют в **публичном** GitHub. Вход на GitHub Pages — только клиентское ограничение интерфейса, не серверная защита от чтения файлов.

**Источником истины проекта является этот репозиторий.** Каждый изменённый файл фиксируется отдельным Git-коммитом, изменения описываются в `CHANGELOG.md`. Разработка не требует отдельной базы или локального хранилища в ChatGPT.
