# История изменений

История реализации хранится также в Git-коммитах репозитория: https://github.com/boxomaha/Karusel/commits/main

## 29 октября 2026 — произвольная площадь и округление вверх

- Фактическая площадь вводится любым положительным числом в см², включая дробное.
- `0 < S ≤ 50 → 50`; `50 < S ≤ 100 → 100`; `100 < S ≤ 300 → 300`; `300 < S ≤ 600 → 600`.
- Площадь свыше 600 см²: **строгий отказ от расчёта**, без вывода себестоимости.
- Показ двух площадей в ответе: фактическая и расчётная.
- Изменены распознавание запросов, сравнения и карточки чата, а также схема данных в подготовленной серверной интеграции ИИ.
- Формулы и ставки по четырём исходным категориям оставлены без изменений.
- Алгоритм формализован в `docs/ALGORITHM.md`; тесты — в `tests/area-tiers.test.js`.

## 29 октября 2026 — чат вместо ручного ввода

- Разделены расчётная модель `calculator.js`, разбор запросов `chat-engine.js`, интерфейс `chat-ui.js`.
- Добавлены вопросы на русском, уточнения в диалоге, сравнение площадей и расшифровка себестоимости.
- Подготовлен серверный обработчик `worker/worker.js` для подключения внешней языковой модели через защищённый API.
- По умолчанию чат работает без внешнего ИИ, с локальным ограниченным распознаванием формулировок.

## 29 октября 2026 — авторизация

- Добавлена форма входа до загрузки интерфейса; расчётные файлы загружаются только после успешной локальной проверки.
- Пароль в открытом виде в исходники не помещается. Данные в публичном репозитории остаются доступными без входа, поэтому это не защита конфиденциальной информации.

## 29 октября 2026 — первая версия

- Excel-таблица шевронов перенесена в статический веб-калькулятор на GitHub Pages.
- Исходные расчётные категории: 50, 100, 300 и 600 см².
