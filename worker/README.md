# ИИ-сервер калькулятора шевронов

Этот Worker добавляет **настоящую языковую модель** к чату на GitHub Pages. Модель только распознаёт смысл вопроса и выдаёт структурированные параметры. Денежные суммы рассчитывает `calculator.js` по формулам — модель не придумывает цифры.

## Требования
- Аккаунт Cloudflare с доступом к Workers.
- Ключ API ИИ-сервиса с OpenAI-совместимым интерфейсом Chat Completions. Это отдельный API-доступ, **не подписка ChatGPT**.
- Node.js и Wrangler (доступен через `npx wrangler`).

## Публикация

В каталоге `worker` выполните:

```bash
npx wrangler login
npx wrangler secret put APP_USER
npx wrangler secret put APP_PASSWORD
npx wrangler secret put AUTH_SECRET
npx wrangler secret put AI_API_KEY
npx wrangler deploy
```

Задайте `APP_USER` и `APP_PASSWORD` равными логину и паролю формы авторизации сайта. Для `AUTH_SECRET` используйте отдельную длинную случайную строку (от 32 случайных байт). **Не записывайте секреты в GitHub**. Ограничьте бюджет, rate limits и доступ к Worker на стороне Cloudflare.

В `wrangler.toml` разрешено изменить `AI_MODEL` и `AI_API_URL`, если используется другой провайдер с совместимым Chat Completions API. Не каждый провайдер гарантирует идентичное поведение; проверьте формат ответов.

После публикации получите URL Worker (пример: `https://karusel-shevrons-ai.example.workers.dev`). В корневом `index.html` замените:

```javascript
const AI_ENDPOINT="";
```

на:

```javascript
const AI_ENDPOINT="https://ваш-worker.workers.dev";
```

Сохраните в GitHub. Дальше вход на страницу будет проверяться также сервером, а вопросы будут отправляться модели с токеном сеанса. Когда сервер недоступен во время работы, сайт может переключаться в локальный режим. Если сервер недоступен при входе, авторизация не будет выполнена.

## Безопасность и границы
- Пароль, ключ модели и секрет подписи существуют только в Cloudflare Secrets.
- Worker проверяет логин на `POST /session`, выдаёт подписанный часовой токен, а `POST /chat` требует токен.
- API-ключ ни при каких обстоятельствах не должен попадать в браузер.
- GitHub Pages остаётся **публичным статическим хостингом**. Файлы калькулятора и история коммитов читаются без входа. Этот Worker защищает доступ к ИИ, но **не делает исходную таблицу конфиденциальной**.
- Для настоящей защиты расчётных данных нужно перенести таблицы и формулы на сервер и отдавать их только авторизованным пользователям. Желательно включить Cloudflare rate limiting для защиты от перебора пароля и затрат на модель.
- Не используйте один пароль для других сервисов. Не коммитьте `.dev.vars` или секреты.
